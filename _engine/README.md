# Homework pages — engine

Not published (GitHub Pages skips folders that start with `_`). Used by Claude's **homework-html-page** skill.

## Who changes what (since 27.10.26)
Several Claude chats save into this folder. Each part has one owner, so nobody saves over somebody else's work:
- **The engine** — `engine/page_template.html` (the code shared by all pages), `index_template.html`, `root_template.html`, `Code.gs`, `build*.py`, `tests/` — is changed **only in the engine chat** ("Движок ДЗ").
- **One homework** — `lessons/<group>-<date>/` (`content.js`, `page.json`, pictures, data) — belongs to the chat where that homework is made (methodology and content together).
- **Feedback, the error database, the tracker** — feedback chats; they don't touch pages.
- Any other chat that needs something new from the engine (a new task type, a new look, a new button) does not edit the engine: it writes an **engine request** for Olya to paste into the engine chat — what, why, an example, how to check it.
- Before saving to the folder, a chat checks that the files there are the ones it built on (`engine/VERSION` and the md5 of what it changes); if someone changed them since, it stops and merges first.
- At the end, a chat that saved anything says in one line which files it changed and how to check them.

## Layout
- `engine/page_template.html` — the whole page except one homework's content; `engine/VERSION` — its version (each page shows it as `ENGINE_VERSION`); `engine/CHANGELOG.md` — what each version changed. A change to the engine: edit the template, raise VERSION, add a CHANGELOG line, then `python3 rebuild_all.py` (all pages + lists) and `python3 check_site.py`.
- `lessons/<group>-<YYYY-MM-DD>/` — one homework: `content.js` (what goes between LESSON CONTENT: START and END: TASKS, texts, boxes…), `page.json` (`title`, `group`, `file`, `earlier`, `assets`), its pictures and data files. Until 27.10 each lesson had a full `page.html` with its own copy of the engine; those copies are in `_old_pages/`.
- `build.py lessons/<name> [SITE_DIR]` → writes `<SITE_DIR>/<group>/<YYYY-MM-DD>.html` (template + content.js + assets, all in one file).
- `rebuild_all.py [SITE_DIR]` — every page + the lists, then `check_site.py`.
- `check_site.py [SITE_DIR]` — every page on the current engine version, no old full pages in `lessons/`, the agreed feedback look still in the engine.
